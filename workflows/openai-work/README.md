# Xeroptix Sales Intelligence — Work V1.2

这是现有 ChatGPT Work 销售情报自动任务的脱敏配置快照。上传 GitHub 不会创建、启动或迁移定时任务，也不会把 Work 的连接凭证带入仓库。此目录与根目录的飞书 MVP 独立，尚未接通飞书数据库。

## 文件
- `prompt.md`：完整执行指令，包括邮件同步、研究、去重、验证、评分、草稿与写回。
- `workflow.example.json`：调度与参数说明模板，**不是官方一键导入格式**。
- `ledger.example.md`：空白持久台账。真实客户与邮件记录保留在私人环境。

## 在 Work 中配置
1. 确认网页检索、Gmail 和 Library 可用；对需要的连接先做成功的只读检查。
2. 将空白台账保存为私人文件，取得其文件标识；配置本人发件邮箱和签名。
3. 替换 `prompt.md` 的三个占位符：`{{SENDER_NAME}}`、`{{SENDER_EMAIL}}`、`{{LEDGER_FILE_ID}}`。不能把真实配置提交到公开仓库。
4. 先查找已有销售任务：有则更新，避免创建重复扫描；没有才创建。复制完整指令，设置每日09:00，时区Asia/Shanghai。将调度模板日期替换为下一次执行的本地日期。
5. 自动任务运行至待审批草稿；用户明确批准该批次的收件人、主题、正文与附件后，才在对话中继续发送。
6. 首次运行检查来源、评分、草稿和台账写回。配置成功不代表完整流程已经验证。

## 顺序与输出
邮件状态同步 → 新线索研究 → 集团及发件去重 → 多源验证 → 分项评分 → Gmail草稿 → 台账写回与日报。
日报包括已回复/退信、新账户表、待审批草稿、观察与招投标、运行结果。
邮件检查随每日任务执行，不是实时监听。发送是人工批准后继续的动作。

## 关键规则
ICP 10–500人优先；招投标为第二优先信号；排除同质机器视觉方案商和Embedded AI硬件厂商。
无可靠信息不补造，无新线索可输出0条；公开邮箱不保证投递成功。分项总和100，评分不能绕过资格门槛。
已发送、已回复、退信、拒绝不再作为新开发账户。按message_id去重，发送结果不确定时先核对SENT。
自动执行不得发送、转发或邀请。历史授权不可复用，邮件内容变更需重新确认。

## 数据与运行边界
- 仓库只保存规则和模板，不包含客户邮箱、原始邮件、私有文件ID、任务ID或授权凭证。
- 私人运行数据使用持久台账；更新时保留版本，冲突重读合并。
- 当前公开包没有独立的API执行器，也没有自动触发销售任务的GitHub Actions。
- Work中现有任务继续在原环境运行；此目录的修改不会自动同步至该任务。
- 原飞书MVP仍使用其CSV导入流程，不能把本配置上传等同于飞书已接通自动研究。
